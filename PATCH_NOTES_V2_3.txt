Market Overlay v2.3 패치노트
============================

v2.3은 설정 구조, 다크모드, 오버레이 표시 방식, 포트폴리오 시각화 가독성, 내부 표 모델 구조를 함께 정리한 사용성ㆍ유지보수 개선 릴리즈입니다.

1. 설정 탭 분리
- 설정 탭을 `일반`, `오버레이`, `시장/갱신`, `데이터/백업`, `업데이트/진단`으로 나눴습니다.
- `일반`에는 화면 테마를 배치했습니다.
- `오버레이`에는 표시할 오버레이, 내 포트폴리오 보기 방식, 비중 기준, 기타 묶기, 금액 표시 단위를 배치했습니다.
- `시장/갱신`에는 시장 지표 기준 주기, 보유종목 현재가 갱신 주기, 이동평균 기준, 시장 지표 선택을 배치했습니다.
- `데이터/백업`과 `업데이트/진단`은 백업, 업데이트 확인, 진단 로그 관련 기능을 맡습니다.

2. 다크모드
- 컨트롤 창과 오버레이 모두 다크모드를 지원합니다.
- 라이트모드는 상승/좋음=적색, 하락/나쁨=청색 기준을 유지합니다.
- 다크모드는 화면 대비와 미국식 색 조합을 반영해 상승/좋음=녹색, 하락/나쁨=적색 기준을 사용합니다.
- 탭, 카드, 입력칸, 표, 매매기록/배당 편집 영역, 포트폴리오 시각화 영역의 다크모드 가독성을 보강했습니다.

3. 오버레이 표시 방식 개선
- 시장, 종합, 내 포트폴리오 오버레이 폭을 같은 기준으로 맞춰 전환 시 크기 흔들림을 줄였습니다.
- 내 포트폴리오 오버레이는 `도넛` 또는 `트리맵`으로 볼 수 있습니다.
- 비중 기준은 `자산별` 또는 `포트별`로 선택할 수 있습니다.
- 기타 묶기는 `N% 미만` 또는 `상위 N개 초과` 조건으로 작은 항목을 하나의 기타 항목으로 합칩니다.
- 기타 묶기 수치는 `▲`/`▼` 버튼으로 명시적으로 조정합니다.
- 오버레이 금액은 `만원 단위` 또는 `원 단위`로 선택할 수 있습니다.
- 내 포트폴리오 오버레이에서 현금비중 도넛을 제거하고 자산/포트 비중과 하단 요약 카드에 집중하도록 정리했습니다.

4. 포트폴리오 시각화와 종목명 표시
- 한국 ETF 축약 표시는 트리맵과 오버레이처럼 공간이 좁은 시각화 라벨에만 적용합니다.
- 포트폴리오 목록과 표에서는 가능한 한 전체 이름을 보여줍니다.
- 일반 한국 종목명은 첫 단어를 임의로 제거하지 않습니다.
- 트리맵/도넛 전환 시 오버레이 높이와 카드 간격이 과하게 흔들리지 않도록 조정했습니다.

5. 조작감 개선
- 설정의 드롭다운과 숫자 입력칸은 마우스휠로 값이 바뀌지 않도록 막았습니다.
- 갱신 주기 선택 표시와 시장 지표 선택 표시를 더 알아보기 쉽게 조정했습니다.
- 오버레이와 설정 화면의 설명 문구를 보강했습니다.

6. 스크린샷 사용자 가이드 갱신
- v2.3 기준 스크린샷 사용자 가이드를 업데이트했습니다.
- 오버레이 화면, 설정 탭, 다크모드, 포트폴리오 비중/트리맵/목록, 매매기록/배당 화면 설명을 최신 기준으로 정리했습니다.

7. 내부 구조 개선
- 매매기록과 배당 표를 `QTableView + QAbstractTableModel` 기반으로 전환했습니다.
- 매매기록, 배당, 포트폴리오 결과, 성과비교, 포트폴리오 시각화, 포트폴리오 편집, 설정/백업/진단 흐름을 handler/model 경계로 분리했습니다.
- 시장 데이터 조회를 `market_data` 패키지로 세분화했습니다.
- worker 실패 로그에 worker 이름, phase, 예외 타입을 남기도록 정리했습니다.
- 백업 검증 실패와 환율 조회 불가 같은 일부 실패 상태에 도메인 예외 타입을 도입했습니다.
- public/private 배포 감사를 강화해 public 레포와 설치 산출물에 커뮤니티용 릴리즈 포스트가 섞이지 않도록 했습니다.

8. 상태 이관
- 기존 state는 v2.3 기본값으로 자동 보강됩니다.
- 테마, 오버레이 표시 방식, 비중 기준, 기타 묶기, 금액 표시 단위가 state와 백업에 포함됩니다.
- legacy `summary` 오버레이 보기 방식은 도넛으로 정규화됩니다.
- legacy `heatmap` 관련 설정은 기존 treemap 호환 정책을 유지합니다.

주의
- 이 앱은 투자 판단을 대신하지 않는 보조 도구입니다.
- Yahoo Finance, CNN JSON, 환율 조회값은 증권사 HTS/MTS와 지연, 환율, 세금, 수수료 기준이 다를 수 있습니다.
- 코드 서명이 없는 개인 빌드라 Windows SmartScreen 또는 보안 프로그램 경고가 표시될 수 있습니다.
