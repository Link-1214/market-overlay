Market Overlay v2.3 사용자 가이드
=================================

1. 설치와 업데이트

- 기존 버전이 설치되어 있으면 v2.3 설치본을 실행해 같은 경로에 업데이트 설치합니다.
- 포트폴리오, 매매기록, 배당기록, 사용자 표시명, 설정은 `%APPDATA%\MarketOverlay`에 보관되므로 업데이트 설치 후에도 유지됩니다.
- 제거할 때만 개인 데이터를 삭제할지 선택합니다.
- 중요한 변경 전에는 설정의 `데이터/백업` 탭에서 백업을 먼저 내보내는 것을 권장합니다.

2. 설정 탭

- v2.3부터 설정은 `일반`, `오버레이`, `시장/갱신`, `데이터/백업`, `업데이트/진단` 하위 탭으로 나뉩니다.
- `일반`에서는 화면 테마를 `라이트` 또는 `다크`로 선택합니다.
- `오버레이`에서는 표시할 오버레이, 내 포트폴리오 보기 방식, 비중 기준, 기타 묶기, 금액 표시 단위를 설정합니다.
- `시장/갱신`에서는 시장 지표 기준 주기, 보유종목 현재가 갱신 주기, 이동평균 기준, 조회할 시장 지표를 선택합니다.
- `데이터/백업`에서는 사용자 데이터를 내보내거나 가져옵니다.
- `업데이트/진단`에서는 업데이트 확인과 진단 로그를 관리합니다.

3. 다크모드

- 컨트롤 창과 오버레이 모두 다크모드를 지원합니다.
- 라이트모드는 상승/좋음=적색, 하락/나쁨=청색 기준입니다.
- 다크모드는 상승/좋음=녹색, 하락/나쁨=적색 기준입니다.
- 시장 카드, 포트폴리오 카드, 성과비교, 매매기록/배당 요약, 오버레이 손익률 바는 현재 테마의 색상 기준을 따릅니다.

4. 오버레이

- 오버레이는 `시장`, `종합`, `내 포트폴리오`를 지원합니다.
- 시장, 종합, 내 포트폴리오 오버레이는 같은 폭 기준으로 맞춰져 전환할 때 화면 폭이 크게 흔들리지 않습니다.
- 종합 오버레이는 시장요약과 주요 지표, 하단 포트폴리오 핵심 지표를 함께 보여줍니다.
- 내 포트폴리오 오버레이는 `도넛` 또는 `트리맵` 보기 방식을 선택할 수 있습니다.
- 비중 기준은 `자산별` 또는 `포트별`입니다.
- 기타 묶기는 `N% 미만` 또는 `상위 N개 초과` 항목을 하나의 기타 항목으로 합칩니다.
- 금액은 `만원 단위` 또는 `원 단위`로 선택할 수 있습니다.

5. 포트폴리오 탭

- `시각화 - 비중`은 도넛 그래프로 자산 또는 포트 비중을 보여줍니다.
- `시각화 - 트리맵`은 박스 크기로 현재 평가액 비중을, 색상으로 선택 기간 수익률을 보여줍니다.
- `목록`은 보유종목을 종합 목록, 포트별, 종목별로 확인합니다.
- 왼쪽 시각화 영역과 오른쪽 목록 영역 사이의 분할선을 드래그해 폭을 조절할 수 있습니다.
- 조절한 폭은 다음 실행 때 복원되며, `기본값` 버튼으로 기본 비율로 되돌릴 수 있습니다.
- 한국 ETF 축약 표시는 트리맵과 오버레이처럼 공간이 좁은 시각화 라벨에만 적용합니다. 목록과 표에서는 가능한 한 전체 이름을 보여줍니다.

6. 매매기록과 배당

- 매매기록은 포트폴리오 탭에서 처리한 매수/매도 기록을 자동으로 쌓고, 수동 추가도 지원합니다.
- 배당 탭은 보유종목 배당 이력을 불러오거나 직접 추가할 수 있습니다.
- 필터는 포트, 종목명, 구분, 통화, 상태, 기간으로 좁힐 수 있습니다.
- v2.3에서는 표 모델 구조가 정리되어 편집, 필터, 정렬 경계가 더 안정적으로 관리됩니다.

7. 업데이트 확인

- 앱은 public GitHub Release를 확인해 새 버전 여부를 알려줄 수 있습니다.
- 앱이 자동으로 다운로드하거나 자동 설치하지 않습니다.
- 숨긴 버전 알림은 설정에서 다시 켤 수 있습니다.

8. 진단 로그

- 설정 탭의 `업데이트/진단` 영역에서 로그 폴더를 열 수 있습니다.
- 로그는 네트워크 실패, 파싱 실패, state 실패, worker 실패를 추적하기 위한 파일입니다.
- 보유수량, 평단가, 예수금 같은 장부 세부값은 로그에 남기지 않습니다.

9. 주의

- Market Overlay는 투자 판단을 대신하지 않는 보조 도구입니다.
- 실시간 초단타용 도구가 아니라 5~10분 단위 시장과 포트폴리오 흐름 확인용입니다.
- Yahoo Finance, CNN JSON, 환율 조회값은 증권사 HTS/MTS와 지연, 환율, 세금, 수수료 기준이 다를 수 있습니다.
