# Market Overlay v2.3

v2.3은 설정 구조, 다크모드, 오버레이 표시 방식, 포트폴리오 시각화, 표 모델 구조를 함께 정리한 사용성ㆍ유지보수 개선 릴리즈입니다. 사용자가 바로 체감하는 변화는 설정 탭이 더 명확해지고, 컨트롤 창과 오버레이가 다크모드를 지원하며, 내 포트폴리오 오버레이를 도넛 또는 트리맵으로 볼 수 있게 된 점입니다.

## 주요 변경

- 설정 탭을 `일반`, `오버레이`, `시장/갱신`, `데이터/백업`, `업데이트/진단`으로 재정리했습니다.
- `일반` 탭에서 화면 테마를 `라이트` 또는 `다크`로 선택할 수 있습니다.
- 라이트모드는 국내 투자자에게 익숙한 상승/좋음=적색, 하락/나쁨=청색 기준을 유지합니다.
- 다크모드는 대비를 우선해 상승/좋음=녹색, 하락/나쁨=적색 기준을 사용합니다.
- 다크모드는 컨트롤 창, 오버레이, 카드, 탭, 입력칸, 표 영역, 매매기록/배당 편집 영역에 함께 적용됩니다.
- `오버레이` 설정에서 내 포트폴리오 보기 방식을 `도넛` 또는 `트리맵`으로 선택할 수 있습니다.
- 도넛과 트리맵은 `자산별` 또는 `포트별` 비중 기준을 지원합니다.
- 기타 묶기는 `N% 미만` 또는 `상위 N개 초과` 조건으로 작은 항목을 합쳐 범례 과밀을 줄입니다.
- 오버레이 금액 표시는 `만원 단위` 또는 `원 단위`로 선택할 수 있습니다.
- 시장, 종합, 내 포트폴리오 오버레이 폭을 같은 기준으로 맞춰 전환 시 크기 흔들림을 줄였습니다.
- 종합 오버레이는 기존 기본 형태를 유지하도록 고정했습니다.
- 내 포트폴리오 오버레이의 현금비중 도넛을 제거하고 자산/포트 비중과 하단 요약 카드에 집중하도록 정리했습니다.
- 오버레이 트리맵/도넛 전환 시 높이와 카드 간격이 과하게 벌어지지 않도록 조정했습니다.
- 포트폴리오 탭은 `시각화 - 비중`, `시각화 - 트리맵`, `목록` 흐름으로 설명과 동작을 정리했습니다.
- 한국 ETF 축약 표시는 트리맵 박스나 오버레이처럼 공간이 좁은 시각화 라벨에만 적용합니다. 포트폴리오 목록과 표에서는 가능한 한 전체 이름을 보여줍니다.
- 설정의 드롭다운과 수치 입력칸은 마우스휠로 값이 우연히 바뀌지 않도록 막았습니다.
- 기타 묶기 수치 조정은 `▲`/`▼` 버튼으로 방향을 명확히 했습니다.
- 시장 지표 선택과 갱신 주기 선택 표시를 더 선명하게 조정했습니다.

## 내부 구조 개선

- 매매기록과 배당 표를 `QTableView + QAbstractTableModel` 기반으로 전환했습니다.
- 매매기록, 배당, 포트폴리오 결과, 성과비교, 포트폴리오 시각화, 포트폴리오 편집, 설정/백업/진단 흐름을 handler와 model 경계로 분리했습니다.
- 시장 데이터 조회를 `market_data` 패키지로 세분화했습니다.
  - Yahoo chart
  - Yahoo dividend
  - FX
  - CNN Fear & Greed
  - facade compatibility layer
- worker 실패 로그에 worker 이름, phase, 예외 타입을 남기도록 정리했습니다.
- 백업 검증 실패와 환율 조회 불가 같은 일부 실패 상태에 도메인 예외 타입을 도입했습니다.
- public/private 배포 경계 감사를 보강해 공개 배포 레포에 소스, 내부 문서, 커뮤니티용 릴리즈 포스트가 들어가지 않도록 했습니다.

## 상태 이관과 호환성

- 기존 state는 v2.3 기본값으로 자동 보강됩니다.
- `ui_theme`, 오버레이 표시 정책, 비중 기준, 기타 묶기, 금액 표시 단위가 state와 백업에 포함됩니다.
- legacy `summary` 오버레이 보기 방식은 도넛으로 정규화됩니다.
- legacy `heatmap` 관련 설정은 기존 treemap 호환 정책을 유지합니다.
- legacy `combined_overlay_layout=treemap_hybrid` 값이 남아 있어도 종합 오버레이는 기본 레이아웃을 유지합니다.

## 검증

- v2.3 설정 탭, 다크모드, 오버레이 표시 정책, 오버레이 렌더링, state migration fixture 테스트를 추가 또는 확장했습니다.
- 매매기록/배당 table model, handler, market data provider, worker failure boundary 테스트를 pre-release 체크에 포함했습니다.
- 오버레이, 포트폴리오 비중, 트리맵, 성과비교 화면의 시각 회귀 스모크 테스트를 유지했습니다.
- public distribution audit를 통과해야 공개 배포 작업을 진행할 수 있습니다.

## 주의

- 사용자 데이터는 업데이트 설치 중 `%APPDATA%\MarketOverlay`에 유지됩니다.
- 중요한 변경 전에는 설정의 백업 내보내기를 먼저 실행하는 것을 권장합니다.
- 앱은 업데이트를 자동 다운로드하거나 자동 설치하지 않습니다.
- Yahoo Finance, CNN JSON, 환율 조회값은 증권사 HTS/MTS와 지연, 환율, 세금, 수수료 기준이 다를 수 있습니다.
- 코드 서명이 없는 개인 빌드라 Windows SmartScreen 또는 보안 프로그램 경고가 표시될 수 있습니다.
