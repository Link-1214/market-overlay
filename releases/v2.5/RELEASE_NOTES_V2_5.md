# Market Overlay v2.5.0

v2.5는 현재 보유분의 평가손익, 계좌의 누적 손익 흐름, ETF 상품 구조를 각각 알맞은 화면에서 확인하도록 정리한 기능 릴리즈입니다.

## 주요 변경

- 포트폴리오의 `총자산`, `보유원금`, `평가손익`, `전일대비`, `현금비중`을 5개 카드로 정리했습니다.
- 현재 보유분 평가손익에는 실현손익ㆍ배당ㆍ입출금을 섞지 않습니다.
- `손익추이`에서 보유원금ㆍ보유평가액, 선택 기간 손익 변화, 누적 총손익과 사건 레일을 함께 봅니다.
- `성과비교`를 `백테스트`로 명확히 바꾸고 진입 시 자동 계산ㆍ10분 캐시를 적용했습니다.
- 포트폴리오와 별도의 `ETF` 탭에서 투자 목표, 운용 방식, 비용, AUM, 업종과 상위 편입종목을 확인합니다.
- 250종은 목록의 한 번 표시 상한입니다. 전체 6,404종을 검색하며 전체 건수와 표시 건수를 구분해 안내합니다.
- 공식 업종 비중이 없는 국내 주식 ETF에는 공식 상위 편입종목과 KIND 업종을 연결한 `상위 편입종목 기준` 보조 구성을 표시합니다.
- 투자 목표는 지수명을 보존하고 명확한 설명부만 줄여 여러 줄로 표시하며, 전체 원문은 툴팁에서 확인합니다. 국가명 뒤의 지수명이 잘려 제공사 이름만 남던 문제를 수정했습니다.
- 레버리지ㆍ인버스ㆍ커버드콜ㆍ역방향 인컴ㆍ변동성 상품의 구조를 일반 설명보다 먼저 표시합니다.
- ETF별 5년 분배 이력으로 최근ㆍ예상 분배율과 주기를 조회하고 24시간 캐시합니다.
- 매매기록ㆍ입출금ㆍ배당을 `장부`로 묶고, 연도별 2×6 월 카드의 분배 캘린더를 추가했습니다.
- 오버레이 헤더에서 바로 숨길 수 있으며 새 화면과 기존 화면의 디자인 체계를 통일했습니다.
- 종합ㆍ내 포트폴리오 오버레이는 보유평가액ㆍ전일대비ㆍ평가손익ㆍ평가수익률 4카드이며, 보유원금은 평가액 아래 자산 수 옆에 표시합니다.
- 가상 계좌로 촬영한 실제 화면의 이미지 가이드를 설치본에 동봉하고 설치본 기동ㆍ종료 안정성을 보강했습니다.

국내 공시 기준일은 운용사별로 다릅니다. BNK 7종은 2026-08-10, TIME 18종은 2026-08-20의 마지막 검증 공식 원문을 사용하며 화면에 실제 기준일을 그대로 표시합니다. 미국 Yahoo 데이터는 실제 구성종목 기준일을 제공하지 않아 수집일임을 명시합니다.

## 계산 기준

- `총자산 = 보유평가액 + 예수금`
- `평가손익 = 보유평가액 - 현재 보유분 취득원가`
- `평가수익률 = 평가손익 / 보유원금 × 100`, `현금비중 = 예수금 / 총자산 × 100`
- `누적 총손익 = 평가손익 + 누적 실현손익 + 누적 배당`
- 외화 취득원가는 매수일 시장환율, 현재 평가는 현재 환율 기준
- 수수료ㆍ세금 차감 전
- 배당과 분배 캘린더는 배당락일ㆍ세전 기준이며 실제 입금일ㆍ실수령액과 다를 수 있음
- 요약 전일대비와 손익추이는 정규장 기준입니다. 개별 종목 행은 활성 프리ㆍ애프터 가격 사용 시 전일 정규장 종가와 비교합니다.

원가를 재현하지 못한 종목은 평가액에는 포함하되 손익에서 제외하고 반영 범위를 표시합니다. 유효하지 않은 분모의 비율은 표시하지 않습니다. 입출금 대비 투자수익률이나 XIRR은 이번 버전의 계산 범위가 아닙니다.

## 설치

기존 v2.4 설치 경로에 그대로 업데이트할 수 있습니다. 사용자 데이터는 `%APPDATA%\MarketOverlay`에 보관되지만, 업데이트 전 설정의 `데이터/백업`에서 백업을 내보내는 것을 권장합니다.

이 앱은 투자 판단을 대신하지 않는 보조 도구입니다. 가격, 환율, 공시와 예상 분배는 증권사ㆍ실제 지급 결과와 차이가 있을 수 있습니다.
