# Market Overlay 화면 사용 가이드 v2.3

이 문서는 Market Overlay v2.3의 주요 화면을 이미지와 함께 설명하는 사용자 가이드다. 화면의 금액과 종목은 예시 데이터이며 투자 판단을 대신하지 않는다.

## 1. 오버레이 화면

오버레이는 컨트롤 창에서 선택한 정보를 작은 항상 위 화면으로 보여준다. v2.3 기준 오버레이는 `시장`, `종합`, `내 포트폴리오`를 지원하며, 세 화면은 같은 폭 기준으로 맞춰져 전환할 때 화면 폭이 크게 흔들리지 않는다.

### 시장 오버레이

![시장 오버레이 라이트](images/user_guide_v2_3/overlay_market_light.png)

- CNN Fear & Greed, VIX, 주요 지수, USD/KRW를 압축해서 보여준다.
- `시장/갱신` 설정에서 체크한 시장 지표만 조회하고 표시한다.
- 빠른 체결 도구가 아니라 5분 또는 10분 단위로 시장 분위기를 확인하는 보조 화면이다.
- 잠금 상태에서는 뒤쪽 창 조작을 방해하지 않도록 클릭 통과 상태로 사용할 수 있다.

### 종합 오버레이

![종합 오버레이 라이트](images/user_guide_v2_3/overlay_combined_light.png)

- 상단은 시장요약과 주요 지표, 하단은 내 포트폴리오 핵심 지표를 보여준다.
- v2.3 최종 기준 종합 오버레이는 기본 레이아웃을 유지한다. 별도 `종합 구성` 선택은 제거했다.
- 포트폴리오 영역에는 설정의 `오버레이 표시 방식`이 적용된다.
- 금액은 기본적으로 `만원 단위`로 절삭 표시해 오버레이 폭 안에서 읽기 쉽게 유지한다.

### 내 포트폴리오 오버레이: 도넛

![내 포트폴리오 도넛 오버레이](images/user_guide_v2_3/overlay_portfolio_donut_light.png)

- 총평가액, 원금, 수익, 전일대비를 카드로 보여준다.
- `내 포트폴리오` 보기 방식이 `도넛`이면 자산 비중을 도넛 차트와 범례로 표시한다.
- 비중 기준은 `자산별` 또는 `포트별`이다.
- 포트폴리오를 하나만 쓰는 경우에는 `자산별`이 더 유용하고, 여러 계좌/포트를 구분해서 운용하면 `포트별`도 의미가 있다.
- `기타 묶기`는 비중이 N% 미만이거나 상위 N개를 넘는 항목을 하나의 `기타` 항목으로 합쳐 범례 과밀을 줄인다.

### 내 포트폴리오 오버레이: 트리맵

![내 포트폴리오 트리맵 오버레이 다크](images/user_guide_v2_3/overlay_portfolio_treemap_dark.png)

- `내 포트폴리오` 보기 방식이 `트리맵`이면 보유 자산을 박스 크기와 색으로 표시한다.
- 박스 크기는 현재 평가액 비중을 뜻한다.
- 색상은 수익/손실 방향을 뜻한다.
- 긴 종목명은 박스 안에서 읽을 수 있는 범위로 줄여 표시한다.
- 내 포트폴리오 오버레이에서는 현금비중 도넛을 따로 띄우지 않고, 자산 또는 포트 비중과 하단 요약 카드에 집중한다.

## 2. 설정 탭

v2.3의 설정 탭은 `일반`, `오버레이`, `시장/갱신`, `데이터/백업`, `업데이트/진단`으로 나뉜다. 화면 관련 설정을 한곳에 몰아두지 않고, 테마는 일반 설정으로, 시장 지표와 갱신 주기는 시장/갱신으로 분리했다.

### 일반: 테마

![설정 일반 다크](images/user_guide_v2_3/control_settings_general_dark.png)

- `화면 테마`에서 `라이트`와 `다크`를 선택한다.
- 기본값은 `라이트`다.
- 테마 선택은 컨트롤 창과 오버레이에 함께 적용된다.
- 다크모드는 회색 계통 배경을 사용하며, 입력칸과 표 영역도 흰색 박스가 튀지 않도록 조정했다.
- 라이트모드는 국내 투자자에게 익숙한 기준에 맞춰 상승/수익/좋은 값은 적색, 하락/손실/나쁜 값은 청색으로 표시한다.
- 다크모드는 화면 대비를 우선해 상승/수익/좋은 값은 녹색, 하락/손실/나쁜 값은 적색으로 표시한다.
- 이 색상 정책은 시장 카드, 포트폴리오 카드, 성과비교, 매매기록/배당 요약, 오버레이 손익률 바에 함께 적용된다.
- 도넛 차트는 항목 구분을 위해 여러 색을 쓰지만, 손익률과 상태 색상은 현재 테마의 상승/하락 정책을 따른다.

### 오버레이

![설정 오버레이](images/user_guide_v2_3/control_settings_overlay_light.png)

- `표시할 오버레이`: 화면에 띄울 오버레이를 `시장`, `종합`, `내 포트폴리오` 중 선택한다.
- `내 포트폴리오`: 내 포트폴리오 오버레이의 보기 방식을 `도넛` 또는 `트리맵`으로 고른다.
- `비중 기준`: 도넛/트리맵의 묶음 기준을 `자산별` 또는 `포트별`로 선택한다.
- `기타 묶기`: 왼쪽 수치는 N% 미만 기준, 오른쪽 수치는 상위 N개까지 표시 기준이다.
- `▲`/`▼` 버튼: 기타 묶기 수치를 명시적으로 올리거나 내린다.
- 수치 입력칸과 드롭다운은 마우스휠로 값이 바뀌지 않도록 막았다. 스크롤 중 설정이 우연히 바뀌는 일을 줄이기 위한 동작이다.
- `금액 표시`: 오버레이 금액을 `만원 단위` 또는 `원 단위`로 선택한다.

### 시장/갱신

![설정 시장 갱신](images/user_guide_v2_3/control_settings_market_light.png)

- `시장 지표 기준 주기`: 시장 데이터를 5분 또는 10분마다 갱신한다.
- `보유종목 전체 현재가 갱신`: 보유종목 전체 가격 조회를 시장 주기와 같은 간격으로 할지, 2배/3배/6배로 늦출지, 수동만으로 둘지 정한다.
- `이동평균 기준`: 시장 카드와 판단 문구에 사용할 이동평균 기준일을 선택한다.
- `시장 지표`: 시장 탭과 시장 오버레이에서 조회할 지표를 선택한다. 체크하지 않은 지표는 조회하지 않는다.

## 3. 컨트롤 창 주요 탭

### 시장 탭

- 상단 버튼은 `오버레이 잠금`, `전체 새로고침`, `오버레이 숨기기`, `종료`다.
- `오버레이 잠금`은 오버레이 클릭 통과/이동 상태를 전환한다.
- `전체 새로고침`은 시장 지표와 포트폴리오를 즉시 갱신한다.
- `오버레이 숨기기`는 오버레이 창만 감춘다. 컨트롤 창은 유지된다.
- `종료`는 앱을 종료한다.
- 시장 카드의 색상은 현재 테마의 상승/하락 정책을 따른다.

### 포트폴리오 탭: 비중/목록

![포트폴리오 비중과 목록](images/user_guide_v2_3/control_portfolio_list_light.png)

- 상단 입력 영역에서 종목, 명칭, 보유수량, 평단가, 시작일, 예수금을 입력한다.
- `추가`는 보유종목을 새로 추가한다.
- `삭제`는 선택한 보유종목을 삭제한다.
- `매수`/`매도`는 거래 수량과 거래가를 기준으로 보유수량, 평단가, 예수금을 함께 반영한다.
- `포트/예수금 저장`은 현재 포트의 예수금 입력값을 저장한다.
- 왼쪽 `비중` 화면은 도넛 그래프로 자산 또는 포트 비중을 보여준다.
- 도넛 아래 범례에는 선택한 묶음 기준의 이름과 비중이 표시된다.
- 오른쪽 `종합 목록`, `포트별`, `종목별`은 보유 목록의 묶음 방식을 바꾼다.
- 보유 목록과 표 영역에서는 종목명을 가능한 한 전체 이름으로 보여준다.
- 한국 ETF 축약 표시는 트리맵 박스나 오버레이처럼 공간이 좁은 시각화 라벨에서 주로 적용된다. 보유 목록 자체를 짧게 줄이기 위한 기능은 아니다.
- 카드 아래 영역은 왼쪽 시각화와 오른쪽 목록으로 나뉘며, 가운데 분할선을 드래그해 폭을 조절할 수 있다.
- 조절한 폭은 다음 실행 때 복원된다.
- `기본값` 버튼은 시각화/목록 폭을 기본 비율로 되돌린다.

### 포트폴리오 탭: 트리맵

![포트폴리오 트리맵](images/user_guide_v2_3/control_portfolio_treemap_light.png)

- `시각화 > 트리맵`으로 보유자산을 박스 형태로 볼 수 있다.
- 박스 크기는 현재 평가액 비중이다.
- 색상은 선택 기간 수익률이다.
- `기간`은 트리맵 색상 계산 기준 기간을 선택한다.
- `트리맵 새로고침`은 선택 기간의 가격 데이터를 다시 조회한다.
- 작은 박스는 글자 겹침을 줄이기 위해 일부 라벨을 생략할 수 있으며, 마우스를 올리면 종목명, 코드, 수익률, 비중, 평가액을 확인할 수 있다.
- 미국 종목은 티커를 우선 표시하고, 한국/일본 종목은 종목명을 우선 표시한다.
- 한국 ETF는 트리맵처럼 공간이 좁은 화면에서 운용사 prefix를 줄여 가독성을 높인다. `SK하이닉스`, `삼성전자` 같은 일반 종목명은 임의로 첫 단어를 제거하지 않는다.
- 트리맵에서도 분할선 드래그와 `기본값` 버튼은 비중 화면과 동일하게 동작한다.

### 성과비교

- 성과비교 탭은 현재 보유종목과 현재 보유수량을 선택 기간 동안 그대로 보유했다고 가정한 단순 비교 화면이다.
- 포트폴리오와 IXIC, S&P 500, KOSPI, 금, 비트코인 같은 벤치마크를 함께 볼 수 있다.
- 반영 항목 수, 제외 항목 수, 데이터 부족이나 조회 실패 같은 주요 제외 사유를 화면에서 확인할 수 있다.
- 이 계산은 매수/매도 시점, 입출금, 세금, 배당 재투자, 환율 변동을 모두 반영한 정밀 백테스트가 아니다.

### 매매기록/배당

![매매기록 다크](images/user_guide_v2_3/control_trades_dark.png)

![배당 다크](images/user_guide_v2_3/control_dividends_dark.png)

- 매매기록은 포트폴리오 탭에서 처리한 매수/매도 기록을 자동으로 쌓고, 수동 추가도 지원한다.
- 배당 탭은 보유종목 배당 이력을 불러오거나 직접 추가할 수 있다.
- 필터는 포트, 종목명, 구분, 통화, 상태, 기간으로 좁힐 수 있다.
- 다크모드에서도 입력칸, 드롭다운, 표 셀의 배경과 글자색이 구분되도록 조정했다.

## 4. 색상과 테마 기준

- 색상 정책은 `설정 > 일반 > 화면 테마`에서 선택한 테마를 따른다.
- 라이트/다크 색상 기준은 특정 화면에만 적용되는 것이 아니라 컨트롤 창과 오버레이 전체에 적용된다.
- 중립값이나 변화가 거의 없는 값은 muted 색상으로 표시한다.
- 예수금 부족처럼 나쁜 상태는 다크모드에서도 하락/나쁨 색상으로 표시된다.

## 5. 데이터, 백업, 업데이트

- 개인 데이터는 `%APPDATA%\MarketOverlay`에 저장된다.
- 백업에는 포트폴리오, 보유종목, 매매기록, 배당기록, 사용자 표시명, 테마, 오버레이 표시 정책, splitter 위치 등 사용자 설정이 포함된다.
- 가져오기 실패 시 기존 데이터를 유지하도록 설계되어 있지만, 중요한 변경 전에는 먼저 백업 내보내기를 권장한다.
- 업데이트 확인 설정도 백업/복원 대상에 포함된다.
- 앱은 새 버전이 있는지 GitHub Release를 확인할 수 있지만, 자동 다운로드나 자동 설치는 하지 않는다.
- 설정의 업데이트/진단 영역에서 자동 확인을 끄거나 수동 확인할 수 있고, 숨긴 버전 알림도 다시 켤 수 있다.
- 진단 로그는 앱 문제를 추적하기 위한 로그이며, 보유수량, 평단가, 예수금, 장부 세부 금액을 남기지 않는 방향으로 설계했다.
- 일본 4자리 종목코드와 `.T` 심볼, JPY 평단가와 JPY 예수금을 지원한다.
- 미국, 한국, 일본 종목명 데이터는 내장 사전과 사용자 표시명 보정을 함께 사용한다. 사용자 표시명이 가장 우선한다.
- 공개용 문서와 스크린샷은 예시 데이터로 만든 화면이며 실제 사용자 장부가 아니다.

## 6. v2.0~v2.3 누적 개선 요약

- v2.0: 계산, 저장, 포맷, 종목명, 히스토리 캐시, worker payload, UI 조립 책임을 분리했다.
- v2.0: 매매기록과 배당기록 필터 초기화, 백업/복원 안내, 설치/제거 UX를 보강했다.
- v2.1: Yahoo 전일 종가 결측 보정, CNN Fear & Greed 조회 안정화, 일본 종목과 JPY 지원을 추가했다.
